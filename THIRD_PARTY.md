# Third-party sources

This is an independent Blender adaptation of RoboDojo, not an official
RoboDojo release or a full Isaac Sim benchmark run.

- Upstream: https://github.com/RoboDojo-Benchmark/RoboDojo
- Checkout used: `08b7ee46034c3d0c8a389b2b7bfc138f4d55ee4d`
- Original predicate source SHA-256:
  `eb928a05c3eb6bae429a922c59e64272c2c3851c22d779143d45627e47b3a504`
- Upstream code is MIT licensed; its notice is retained in
  [LICENSE.robodojo](LICENSE.robodojo).
- `assets/official/` contains the task-specific official robot, object and
  layout assets used for the reproduction. Blender scenes embed those meshes.
  They remain third-party assets; this repository does not assert original
  authorship or grant new rights over them. Consult upstream asset terms before
  reuse; the code license must not be assumed to license every asset.

The control, adaptation, collision-checking, diagnostic, rendering and report
files record this project's work. Grasping is scripted/kinematic, not force
controlled. Cube motion is generated by Blender rigid-body dynamics.
